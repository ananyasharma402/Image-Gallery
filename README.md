# 🖼️ Interactive Image Gallery

An interactive and responsive Image Gallery built using **HTML, CSS, and JavaScript**.

This project displays multiple images in a responsive grid layout. Users can hover over images for animation effects and click on any image to view it in a larger lightbox.

---

## ✨ Features

- 🖼️ Displays 8 images in a responsive grid
- 🔍 Click on an image to view it in a larger size
- ✨ Smooth hover and zoom animations
- 🌑 Lightbox with a dark background
- ❌ Close button to close the enlarged image
- 🖱️ Click outside the image to close the lightbox
- 📱 Responsive design for different screen sizes
- ⚡ Uses DOM Manipulation and Event Handling

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
